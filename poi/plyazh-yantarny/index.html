Янтарный · Пляж

Центральный пляж Янтарного

Морской берег у центральной части Янтарного. Для спокойного дня его можно сочетать с променадом, оставив время на дорогу из других городов.

В вашей прогулке

Проверяйте условия купания, ветер и доступные подходы. Актуальные сертификаты пляжа не подтверждены этой карточкой.

Это место

Спуски из парка

Из парка Беккера к Центральному пляжу ведут три спуска: центральная лестница с четырьмя маршами, спуск для колясок и лестница у липовых аллей. На пляже есть деревянные дорожки и оборудование для помощи маломобильным посетителям. Нужную помощь уточните у сотрудников.
